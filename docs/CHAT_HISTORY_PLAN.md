# 聊天历史检索与收藏阶段

沿用 Java/MP/XML 与现有 chat-service，不新增服务或搜索中间件。前后端同步提供会话内纯文本搜索、消息收藏/取消、分页收藏和清空本会话收藏。

## 不变量与范围

- 所有操作锁定 ACTIVE 会话后确认当前成员，与踢人/解散串行化；查询严格排除入群序号及以前的消息。私信拉黑不擦除已可读历史。
- 搜索是区分大小写的字面包含匹配，2～64 字符，`%/_/=` 不作为通配符。一次最多扫描 2000 个序号、返回最多 50 条；无匹配仍可能返回更早扫描游标，不假装检索结束。按序号倒序，不做全文相关度排序。
- 收藏只保存本人对真实消息的引用，不复制正文、不对其他人暴露设置。每人每会话最多 1000 条，重复收藏/取消幂等。收藏不授予永久访问权；被移除、解散或重新加入后，原历史不可通过收藏绕过。
- 清空只删除当前成员在本会话的个人收藏，包括已失去历史读取权限的旧引用；前端确认，不影响消息、其他人的收藏或已读状态。
- 搜索/收藏面板不自动把聊天尾部标为已读；旧异步响应、切换会话和组件卸载不能覆盖当前视图。
- 新增 Flyway V3，不修改既有迁移。SQL 以参数绑定、序号索引、有界扫描和超时约束执行；这不是搜索引擎或容量压测的替代。
