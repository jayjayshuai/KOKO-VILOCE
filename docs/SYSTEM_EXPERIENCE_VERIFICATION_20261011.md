# 系统体验优化验收（2026-10-11）

## 本轮实现与实际发布

- 语音目录提供“加入并发言”和“只收听”。房主发言点击串行完成入房、选空麦位、允许本人发言、连接和请求设备；不先创建多余听众连接。
- 普通成员一次点击提交申请并开始收听，等待房主批准。房主一次“同意发言”串行确认席位审批与解除房间闭麦，部分失败仍显示真实结果，不吞掉未知提交。
- 发布设备前消耗一次明确意图；拒绝授权、连接失败、刷新、返回、换登录身份不会循环采集。普通成员在后台获得批准不采集，回到可见房间且意图仍有效才继续。
- “只收听”可取消发言准备，设备释放期间阻止并行重新开启；取消未消费意图后晚到的批准不能复活采集。注销、离房及组件卸载仍清理当前作用域。
- 常驻条按实际高度为页面留出底部空间；观察器随条出现/消失或卸载释放，320/390 像素小屏不遮挡可滚动到的末尾操作。
- 登录与注册原生校验失败有可见行内提示，提交期间冻结输入和模式切换；注册使用 new-password 自动填充语义，成功后清除表单密码。没有据此认定此前朋友浏览器故障的具体原因。

前端已独立增量发布，并保留校验过的备份。仅重建前端静态容器，HTTP/TLS 边缘配置检查和正常重载通过，未触发回滚；没有重启 Java 或中间件、修改后台配置、执行生产数据库迁移。联调只使用明确测试账号和自建测试房间，房间关闭及会话退出已确认。

## 使用与剩余范围

进入语音空间点击“加入并发言”：房主直接开始，普通成员等待房主“同意发言”；首次弹出设备权限时选择允许。只听别人请点“只收听”。切页可通过常驻条返回或离开；禁麦后再次获准需自己重新点击开始发言。

浏览器/系统冻结、手机锁屏、杀进程及整页刷新不承诺持续通话；不在后台偷偷采集。LiveKit 独立包大小警告保留，没有调高门槛或将库全部提前加载。未进行多实例容量、实体移动设备矩阵或八路压测。

全系统仍有独立待验收范围：已有创作者/通知编辑恢复工作区、聊天弱网/多节点容量、Discord OAuth、直播播放器/转码/回放、真实告警/备份恢复及支付对账。本轮不将其标为完整上线。
