# 常驻多人语音实施计划

本轮需求：站内切页不中断已有通话、浏览器标签页后台尽量保留通话、多人同时发布音频、房主控制成员发言权限。

## 不变量

- 房间视图可以缓存，但只保留当前房间的一条媒体连接；换房、换登录身份和注销不得复活旧连接或设备。
- 切页不自动签发新凭据、不重放JOIN、不打开麦克风；常驻通话条操作同一条真实连接。
- 主动离房先停止本机音频，再核验和提交LEAVE；超时不假装服务器已离房。
- 每房八个麦位支持同时发言，不因其中一人上麦撤销其他成员的发布权限。
- 非房主不能自行解除房间闭麦；被禁麦后重新上麦默认仍闭麦，必须由房主允许，不能通过客户端按钮或API绕过。
- 后台仅延续已经连接的通话，持续执行授权核验和租约；浏览器/系统冻结导致核验过期仍失效，无法承诺手机锁屏持续运行。

## 阶段与验收

1. 缓存房间视图、常驻通话条、媒体状态与身份轮次隔离；用真实通话验证站内往返无新增JOIN/凭据/采集。
2. 已连接通话的标签页后台核验/续约及明确离房的本机释放；验证后台事件、恢复、注销和设备清理。
3. 服务端房主开麦授权和成员列表管理入口；验证成员直接API解除禁麦失败、真实SFU撤权及两个成员同时发布/收听。
4. 精确暂存树测试/构建、生产增量发布和线上独立账号验收；只提交本轮源码/测试及脱敏记录，保留无关工作区修改。
