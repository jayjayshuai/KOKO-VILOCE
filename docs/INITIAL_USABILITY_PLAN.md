# 初步可用版本交付计划

2026-10-07 根据用户要求，先形成可演示、可调试、可如实写进简历的版本。
原企业路线保留；初步版本按核心业务验收，不以全部高级开关打开作为目标。

## 本轮

1. 修复 Gateway WebSocket 包装与自动配置重复 Bean 的启动失败，保留原握手配置；
   完整本地 Boot、真实 WS 生命周期和线程检查。
2. 公开发现按内容、创作者、社区、语音、直播分区独立读取和重试；
   故障显示错误，未知统计不显示成零；正常分区不等待慢服务。
3. 增加无凭据、无写入的实际 HTTP 环境检查；分别记录本地最新源码与远程已部署版本。
4. 恢复 SSH 连接远程中间件的只读本地调试，验证 JDWP 实际断点；
   同时提供 SSH 转发访问现有部署的演示入口。
5. 删除 SHA-256 完全一致的历史验证副本和已解压安装包，保留原件、备份、运行依赖和源码。
6. 提交实现、回归和项目介绍；阶段状态和未验证部分明确记录。

本轮1～5已执行并验证，前端独立发布及19份公网产物核对通过。
后端候选未发布；当前结果与后续完整业务写入验收分别见
[验证记录](INITIAL_USABILITY_VERIFICATION_20261007.md)。第6项以Git提交和远程推送事实为准。

## 后续核心验收

逐域核对现有部署的 Flyway 版本和当前源码差异，先备份与验证迁移，再发布相关服务；
本地调试不自动升级现有项目数据库。目标是在匹配版本的环境，以两个独立会话完成
账号→主页/文章→关注互动→社区→私信/群聊→通知，记录真实结果和精确测试数据清理。

语音正式开放的条件包括同源 HTTPS/WSS、SFU 私有信令入口、服务器麦位权限、
持续授权和旧音轨清退、双浏览器真实音频。视频/Discord 外部适配按原路线继续推进。

发布、容量、外部告警与备份恢复仍需各自证据；初步版本不会据此声明大规模高可用。
可使用的简历说明和演示顺序见 [项目介绍](RESUME_PROJECT_GUIDE.md)。
