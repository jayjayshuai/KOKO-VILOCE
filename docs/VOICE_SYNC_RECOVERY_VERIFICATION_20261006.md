# 语音房状态同步与提交结果恢复

2026-10-06 候选开发批次；未部署，不宣称语音媒体或正式上线完成。
沿用语音互动核心默认关闭与媒体准备度固定 `false`，没有新增或自动应用数据库迁移。

## 实现边界

- `GET /api/voice/rooms/{id}/interaction/sync?knownVersion=...`：锁定房间后先惰性回收租约、
  核对当前有效成员或房主权限，再比较字符串版本。同版本返回核验时间而不重复发送名单；
  变化、首读或客户端版本超前返回完整当前授权快照。关闭或过期会话不能用旧版本绕过授权。
- `GET /api/voice/rooms/{id}/interaction/receipts/{requestId}`：锁后读取登录用户自己的持久收据。
  离房或房间关闭后仍可核对原提交，不续约、重新加入或调用媒体。未查到不代表在途写入失败。
  不提供他人身份参数、指纹或第三方会话；回复 `no-store`，对象日志脱敏。
- 前端首次/手动/提交后完整读取，正常轮询按版本同步；版本全程字符串，不转换JS number。
  变化时整体替换快照，不拼接旧房管名单；网络读取失败锁新命令、清审计并标记旧快照。
  401/403/404清除私有快照及能力；审计授权拒绝同样立即失效。
- 浏览器离线或隐藏停止读取和心跳，恢复前台重新授权读取，不自动加入或重试写入。
  原未知命令仍保留不可变UUID/参数；明确“只查询原提交结果”不发第二次写入。
  收据类型/提交版本不匹配或查询失败不消除未知状态，也不恢复原JOIN会话。
- 失败读取按5/10/20/40/60秒有界退避；手动刷新绕过退避。15秒未获当前核验时锁新操作。
  本机核验时刻仅用于显示和保守UI锁定，不判断数据库租约。卸载/换身份取消旧请求和监听。

这是条件轮询和故障恢复，**不是Netty房间事件总线、SSE或LiveKit媒体权限系统**。
数据库准备阶段仍有房间锁和有界事实查询，不以少发JSON声称数据库容量已认证。

## 本地调试现状

用户选择连接现有远程项目库，仅限谨慎调试。私有启动桥及IDE配置均忽略、不提交。
本机8个JVM健康与JDWP握手通过，7个业务数据源同时核验JDBC只读及MySQL会话只读；
后台Spring定时任务/Flyway/消费者关闭，HTTP写保护通过。远程中间件通过环回SSH转发，
Nacos/RPC分组及Redis调试DB与生产隔离，无生产容器重启或数据库升级。

现有远程Schema落后：身份缺运营版本、语音缺互动V3、聊天缺同步版本表。
语音发现实际500，不能把进程健康当作完整业务联调通过；不借只读调试申请擅自迁移生产。
启动桥护栏不是数据库只读账号授权：调试器手动求值仍可能绕过配置，禁止手工写SQL。
