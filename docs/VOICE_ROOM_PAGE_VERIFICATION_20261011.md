# 独立语音房间页与直接入口

2026-10-11，按用户提供的enterprise-development规范实施、冻结回归并发布。
本轮修复“点击房间后仍停留在窄操作弹窗”的体验，不把页面导航当成已经建立语音。

## 实现与边界

- 列表按钮改为“进入房间”，实际导航到`/voice/rooms/:roomId`，由RouterView渲染独立房间页，无弹窗遮罩。
  详情页要求恢复可信账号，隐藏于侧栏普通导航；非法、溢出或非规范ID不发送房间请求。
- 明确列表点击携带一次身份/登录轮次/文档限定的导航意图。首次房间页消费后以null覆盖历史标记，
  保留Router字段并防止后续历史合并复活；刷新文档的时钟不同，旧意图不能跨刷新、账号或登录轮次重放。
  标记仅为交互意图和公开名称，不是权限、Cookie或JWT；授权仍由服务端完成。
- 明确进入时串行核验房间、必要时JOIN、再请求真实收听连接；未知JOIN结果、失权、取消或身份变化不进入SDK。
  已有成员会话不重复JOIN；默认不调用麦克风。声音能力尚在读取时等待核验，不以未读取的false误报已关闭。
- 刷新/分享地址只打开页面，不自动入房或录音。已有会话但未连接时由本人点“连接语音”；未加入者点“进入并收听”。
  名称来自已选择的公开快照，仅作展示；刷新后没有名称提示时使用通用房间标题，不依赖发现列表的12条限制阻止访问。
- 声音状态/设备控件位于页内靠上位置，成员列表、发言控制及高级房管功能同页显示。
  未获得成员快照显示未知数量，不伪造空房。成员数是租约数，不冒充RTP在线人数或已听见。
- “离开房间”等待实际提交和当前事实确认后返回列表；未知结果不悄悄跳走。
  普通返回只退出页面、停止本地连接与续约，不宣称服务端成员瞬时全部清退。

## 实际验证

最终冻结前端250项测试，失败/跳过0；类型检查、生产构建通过。
新增覆盖地址格式、导航意图一次消费、刷新/账号隔离、入房顺序、已有会话、未知JOIN及不自动调用设备。
后端没有修改，本轮没有冒用历史后端测试计数。

公网用两个既有合成测试账号，真实注册身份库、Cookie、API、WSS及自建LiveKit，无身份/接口/SDK桩、不忽略TLS错误。
输入为生成WAV经真实getUserMedia，不采集个人麦克风；另记录真实设备调用次数，确认只进房不会请求录音。

验收范围：实际表单建房 → 列表一次点击 → 独立地址/页面 → 自动JOIN和收听连接 → 本人上麦/解除闭麦/明确开启设备 → 对端解码音频；
刷新未重放JOIN/凭据或打开设备，显式重新连接继续接收；实际LEAVE后返回列表。
测试房间由拥有者确认关闭，不操作用户房间或账号。桌面/移动视口不是实际手机硬件验收。

## 发布与保留工作

发布前备份旧前端及配置并验证摘要，使用独立受保护目录切换；只重建项目Web并加载既有代理，
其他业务JVM、数据库、Redis、Nacos及LiveKit未重启，无数据库结构迁移。
保留旧管理入口和后台安全约束；能力故障、浏览器阻止播放、麦位变化后重新核验的反馈继续有效。
Vite仍报告LiveKit懒加载块较大；容量、弱网、后台持续通话和实际个人硬件仍需专项验收。

App.vue与既有测试文件仅暂存房间入口及路由清单的精确增量，未混入其他创作/通知/编辑器工作。
原XML排版、用户手册与学习文档、其他未发布代码保留；私有配置、密码、Cookie/JWT、备份SQL和运行证据不提交。
