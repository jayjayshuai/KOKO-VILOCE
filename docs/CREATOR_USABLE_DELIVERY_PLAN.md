# 创作者功能交付计划

本阶段将既有编辑器恢复代码从仅本机夹具验证推进到真实账号、真实业务 API 和上线闭环。

## 不变量

- 草稿保存、发布分别确认；结果未知仅查询事实，不自动重发创建、发布或归档。
- 私人草稿正文不进入公开发现；其他作者不得更新、发布或归档本人内容。
- 编辑器未保存提醒统一用于关闭、切换内容、退出和路由离开；在途与未知提交说明不同。
- 本机表单作用域包含身份、登录轮次、编辑对象；旧请求不能覆盖新表单或使用新账号继续发布。
- 归档使用当前已确认版本，确认后移出列表；回复丢失不能乐观隐藏或重复发送。
- 只操作测试账号新建对象；生产凭据、正文证据、截图和恢复日志不进入 Git。

## 阶段

1. 审查既有文章/主页编辑、互动读取与未保存保护，选择精确源码；通知独立改动继续保留。
2. 补齐工作台已发布内容查看及归档入口、归档未知结果恢复和跨身份回归。
3. 精确候选测试/构建、实际保存/发布/访客查看/他人拒绝/归档验证，并检查移动端及语音回归。
4. 增量前端发布、线上复验、脱敏记录及分阶段代码提交；不因前端功能启动私有 prod 配置或执行迁移。

跨刷新私有草稿存储、服务端幂等收据、本人列表分页与多人编辑仍是独立范围，不将内存恢复宣称为零丢失。

本轮上述阶段在文章闭环、主页私人草稿及编辑器恢复范围内已完成候选和线上验收，见[创作者交付记录](CREATOR_USABLE_DELIVERY_VERIFICATION_20261011.md)。主页公开发布仍只有本机夹具恢复验证，图片真实上传、主页下线入口及分页不因本轮完成而勾选。
