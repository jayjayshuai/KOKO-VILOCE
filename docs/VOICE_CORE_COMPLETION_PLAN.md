## 不变量

- 入会身份来自网站会话，成员/麦位/关闭事实来自数据库；不能靠前端按钮授权。
- 无页面访问时过期成员仍须回收并提交旧身份退场；发现列表不是写入依据。
- 旧JWT不可绕过Gateway，已撤销连接不能通过SDK自动恢复重新发布。
- TLS私钥/ACME账号/服务器配置/数据库备份不进入源码、日志输出或Git。
- 只变更本项目及明确的代理片段，保留用户XML修改，不停共享数据库、Broker或Nacos。

## 本轮网站会话清退与开放验收

- 新增V6，仅保存高熵登录令牌的域隔离摘要，不保存Cookie或可登录令牌；摘要只由网关生成。
- 首次签发绑定当前网站会话；换网站会话推进不可变媒体UUID/轮次，旧退场完成前不签新JWT。
- 注销先撤销网站会话，再按当前摘要登记旧身份退场；迟到的旧注销不得影响新摘要/UUID。
- 注销的持久登记失败必须告知调用方，不能返回“已完整清退”；WS核验提供补偿，租约回收仍保留。
- 本地实际SQL验证回滚、并发、旧/新会话隔离；原生SDK验证注销时对端成员和音轨清理。
- 冻结包、备份、定向迁移发布后，再做公网真实前端双向RTP/注销/离房/关房验证，通过后开放。
