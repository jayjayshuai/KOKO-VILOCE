# 语音同步与麦位冲突体验验收（2026-10-11）

## 本轮范围

解决通话期间的刷新感、反复红字以及麦位竞争后被误锁为未知请求的问题。沿用 Java 微服务与自建 LiveKit，本轮只增量发布前端；未发布后端、修改业务表结构、重启 LiveKit 或共用中间件。测试仅使用独立测试账号和测试房间，未操作用户正在使用的房间或麦克风。

## 变更与不变量

- 前台操作、静默同步与静默续约分离；高级媒体诊断的后台读取也不改变前台 `loading` / `aria-busy`。相同诊断保留对象引用，普通前台焦点切换不清空进度。离线、后台或失去权限仍清除私有诊断。
- 正常同步和已知短暂网络/服务失败使用稳定、中性的状态区域，减少按钮位置变化。错误在重新读取等待时保留，仅在真正成功后清除；不假装续约成功。
- 同步失败仍使权限快照失效并暂停新命令/连接；401/403/404 等明确拒绝仍保留警示及权限撤销。没有放宽已有授权有效期或自动开启麦克风。
- 首次写请求收到本站匹配 HTTP 状态的 `BAD_REQUEST` / `VALIDATION_ERROR` / `FORBIDDEN` / `NOT_FOUND` / `CONFLICT` 拒绝契约时，停止该操作并重新读取事实，不把它当成未知提交。HTTP 层保留错误码；裸状态码、5xx、超时或错误码不匹配不得推断未提交。
- 原请求曾经超时或结果未知时，后续原 UUID 重试即使被拒绝，也仍保留未知请求；不能排除更早的提交，不自动换 UUID 或重发。
- 新手申请/上麦在前置核验完成后重新选择当前角色与空席位；已经在麦或等待申请时不重复提交。高级操作不能给已在麦的目标再次邀请或抱麦。
- 实际声音连接成功后清除旧入房失败提示，不清除未知写入或当前设备错误。房间详情仍标记语音空间导航位置，指引不再引用详情页不存在的步骤编号。

## 发布与使用

发布来自独立冻结暂存树，未打包工作区内其他创作者/通知等未完成修改；旧前端已备份，HTTP/TLS 入口配置校验与平滑重载成功。服务器前端健康检查通过，回滚未触发。浏览器需重新加载才能使用新代码；正在通话时先结束通话，再强制刷新，避免主动重载中断自己连接。

测试不覆盖所有实体手机、浏览器权限弹窗、真人麦克风、复杂弱网、多人容量或长时间稳定性。网络读取不能核验权限时仍会暂停声音连接；需要重新核验并由用户明确连接/开麦，不以体验优化代替授权安全。
