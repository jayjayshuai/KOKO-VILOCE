# 语音房实施计划

依据用户2026-10-05指定的[语音房方向](../backend/VOICE_ROOM_PLAN.md)，继续企业路线，
优先P0安全边界，再做麦位、实时事件与前端。方向稿中的描述须以源码/实际证据复核。
视频/Discord取舍仍为建议，不删除原功能；钱包/支付/录音均不因建议稿直接上线。

## P0

1. 网关清除不可信身份与内部密钥头；语音业务与文档仅接受内部密钥，私有操作须正数long身份。
   密钥缺失/空白/过短启动拒绝；唯一匿名业务例外为GET发现（仍需网关密钥）。
   直连/重复头/超界均不得进入业务，入会令牌响应不缓存。下游仍检查房主归属。
2. 补投递异常可定位的安全原因链，不输出供应商/SQL消息中的密码、令牌或用户内容。
3. 真实多实例文本/房间事件分发、故障恢复及断线事实重取；不把单机内存事件当扩容完成。
4. 域名HTTPS/WSS、备份恢复、告警receiver与至少一种真实推送；缺凭据/付费需明确提出。
