## 不变量

- 只重放 DEAD，不修改事件 ID/载荷/业务关系；SENT、RETRY、IN_FLIGHT 均拒绝。
- 同库事务锁定事件、校验版本、写审计并重新排队；审计失败必须回滚事件状态。
- requestId 绑定操作者、事件、预期代次和原因；同请求重复返回既有受理结果，异载荷冲突。
- replayGeneration 单调递增；每轮 attempts 可重置，但 totalAttempts 累计不减，历史失败进入审计。
- 原领取 token 已失效，重新排队不复用租约；旧领取者无法确认新一轮。
- 权限来自服务端当前有效 RBAC，无默认管理员或客户端可信角色；写操作需本人密码二次确认。
- 普通用户不看运营队列；审计只追加，不提供更新/删除 API，不宣称 DBA 也无法修改。
- Gateway/Sa-Token 统一授权，各业务域再次授权；允许域为 identity/community/live 固定白名单。
