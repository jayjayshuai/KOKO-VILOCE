# UP主公开主页交付计划

承接创作者和通知闭环，复用Java Gateway→Dubbo→身份域已发布主页/关注接口，不迁移数据库、不启动私有prod配置。

- 公开路由按slug直接读取，未发布/不存在显示明确不可用；不拿发现页缓存或私人主页替代。
- 路由、身份及登录轮次隔离请求；旧读取/写回应不能覆盖新主页或新账号。
- 关注状态GET确认前不能切换，未知写入保留核实入口，不自动重发；GET是时点事实，不是写入收据。
- 发现卡片、本人已发布主页和已关注列表提供真实详情入口；分享地址来自当前站点和已确认slug。
- 私人资料与公开读取分别验收，文本转义、移动布局、无障碍及既有语音保留。
- 冻结源码测试/构建→实际专用账号草稿/发布/访客/关注与通知/未知回应验证→保留旧哈希资源发布→线上复验/阶段提交。

作品列表按作者分页、主页下线/审核、跨刷新提交收据与实体手机后台认证是独立范围，本轮不伪造。
