# 受控语音使用指南

使用已部署站点的HTTPS地址，入口为`/koko/#/voice`。
旧HTTP网站会跳到HTTPS；项目API不能再用公网明文HTTP。域名/IP、密码和私有部署配置不在本指南提供。

## 开始通话

1. 注册或登录自己的账号。首次演示建议两台设备分别登录两个账号，并使用耳机避免回声。
2. 在“我的语音房”`/koko/#/studio/voice`点击“创建语音房”，填写标题、唯一地址、话题及人数。
   默认创建受控房间；旧LEGACY房间保留数据但不再显示成可以正常连麦的房间。
3. 在语音空间找到房间，点击“加入讨论”，打开引导面板。第1步点击“加入房间”。
4. 第2步默认“只收听”，无需申请麦位。要说话则选择“我要发言”：房主点“自己上麦”；
   普通成员点“申请发言”，等待房主在“有人申请发言”区域“同意发言”。
   如果提示闭麦，再点“允许我发言（解除闭麦）”。这些操作只改变授权，不能远程打开设备。
5. 第3步点击“连接语音”，等待实际“已连接”，再点击“开启麦克风”，
   允许浏览器使用麦克风。授权可发布不等于设备已经开启，不能由房主远程打开他人的麦克风。
6. 如果提示浏览器阻止播放，点击“恢复声音播放”；这只恢复收听，不会打开麦克风。

“连接语音”会先等待旧授权清退，界面显示“正在准备并连接声音”，有界读取最多约10秒。
就绪后仍由服务端重新授权；如果准备超时或房间权限变化，会明确提示重新连接，不自动重发房间命令。
面板会区分“只有你连接声音”“对方已连接但没有音轨”“已订阅对方音轨”。
音轨订阅不是实际听音证明，仍需检查设备、输出音量及播放权限。

麦位、预约、房管与审计放在高级区域；媒体授权和退场进度默认折叠，不影响正常通话。
语音面板请保持打开、前台可见以续约。手机锁屏、切后台会失效并停止通话，恢复前台须重新连接，不会自动开麦。
普通前台焦点切换只复查状态；复查失败、离线或授权过期仍会停止旧连接。
要完整退出，点击“离开房间”或注销；
关闭面板会停止续约，不等于服务器瞬时撤销所有成员事实。房主关闭房间会清退所有参与者。

## 常见情况

- 麦克风权限拒绝：在当前HTTPS站点的浏览器权限中允许，检查系统权限和其他应用占用，再重试。
- 没有声音：两端用不同账号、同一房间，都需真正“已连接”；说话的一端需发言授权及设备开麦。
  仅上麦不代表设备开启，连接人数也不代表已有音轨。检查手机媒体音量、蓝牙输出及声音恢复提示。
- 注册提示“邮箱或用户名已被注册”：使用原账号登录，或换未注册的邮箱及用户名。
  不要重复注册同一邮箱；服务故障与注册冲突分开提示，不因失败提示擅自重置账号。
- 换登录后暂不可连接：旧网站媒体身份正在清退，等待几秒后重新连接；不要复用旧JWT。
- 断开或版本冲突：重取房间事实，按当前状态操作；不要重复创建新的未知写入请求。
- 接口依赖暂不可用：不会返回假连接或偷偷恢复旧权限。管理员应检查真实退场任务和服务依赖。

已通过公网真实双浏览器生成音频、注销/离房/关房及新旧会话隔离测试；
个人设备听音、弱网、移动端与多人容量需在使用环境继续验证。测试时间不是生产SLA。
