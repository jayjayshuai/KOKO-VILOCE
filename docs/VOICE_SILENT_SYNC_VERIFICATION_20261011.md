# 语音静默同步与连接点击验收

2026-10-11，按用户提供的enterprise-development规范执行。
本轮仅修复语音前端状态和操作时序，后端、数据库结构、认证策略及共享中间件没有修改或重启。

## 复现与实现

旧版每5秒的成员同步使用前台loading，禁用连接按钮并显示“读取中”，最近核验时间也在主区域反复变化。
每25秒续约复用操作busy及写请求控制器。连接函数在读取/权限不满足时直接return，缺少点击反馈。

使用自己的真实测试账号和房间，保留实际同步响应内容，仅延迟一条真实GET响应。
在线旧版复现：同步在途时连接按钮不可用、aria-busy=true、刷新按钮显示“读取中”，并非整页真的导航重载。

本轮实现：

- 前台loading、静默refreshing、后台renewing分离，同版本同步不重建名单/能力对象。
  后台请求不清掉错误再闪回，不占用前台忙碌状态，不让按钮、提示和布局反复变化。
- 明确新操作可抢占后台读取和续约的客户端等待；续约使用独立控制器、轮次及错误反馈。
  抢占不能撤销服务器已续的租约；旧反馈不能覆盖新命令busy/结果，未知业务写入仍保留原UUID/参数。
- 连接点击先显示权限核验，优先取得最新快照、等待Vue属性更新后才申请媒体。
  重复点击只建立一次；取消、身份/会话变化或撤权后旧准备不得重新进SDK，失败不静默吞掉。
- 正常同步保持15秒授权核验期限及失败退避；隐藏、离线、读取拒绝或当前续约401/403/404/409仍失效旧权限。
  静默不表示忽略错误，不增加服务端权限或自动开启麦克风。
