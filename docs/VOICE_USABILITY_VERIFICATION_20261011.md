# 注册修复与受控语音使用闭环

2026-10-11，按用户提供的enterprise-development规范实施、冻结源码、回归和分批发布。
本记录补充[既有语音验收](VOICE_AVAILABLE_VERIFICATION_20261011.md)，不代表全平台或移动硬件验收完成。

## 本轮修复

- 重复注册原本携带Spring/MySQL异常cause跨Dubbo STRICT传输，编码失败成为500。
  改为固定消息、无数据库cause的注册冲突契约，显式声明RPC异常并精确加入白名单，返回409。
  必需注册命令也显式列入白名单，未放宽STRICT或Serializable检查。唯一约束及已有账号保持不变。
- 输入校验400仅给格式说明，不输出拒绝的密码/邮箱。RPC故障503明确写入结果未知，不误报已回滚。
- 语音主面板分为加入、查看收听/发言指引、连接声音三步。
  房主可直接本人上麦，普通成员明确申请，房主在主面板同意，设备仍必须由本人点击开启。
  麦位/角色/预约/审计折叠；技术媒体计划不默认挂载和轮询。
- 新操作先核验最新状态；前置读取独占窗口，轮询/续约不抢占它。
  核验失败、离线、隐藏、换账号或登录轮次后不发送。
  已发送结果未知的UUID/会话/版本保持原样，不能因本改动偷偷新建或自动重发写入。
- 房间读取期间禁止新连接，但不以定期读取为由切断已有连接。
  点击连接后最多约10秒有界读取旧媒体清退进度，然后仍由后端重新核验并签发凭据。
  准备期间取消/失权/换版本不继续申请凭据，不自动请求麦克风。失败明确提示重新连接。
- 前台焦点变化不清空近期有效授权，后台、离线、读失败或授权过期仍停止旧连接。
  显示设备是否开启、仅收听、只有本人连接、对方未发布音轨或已订阅音轨；不把订阅当成已经听见。
  切换用途只是操作指引，不暗中开关设备。
- 增加语音事实接口脱敏失败/取消日志，仅固定端点类别、状态或取消，不记录房间ID、查询串、Cookie、JWT或请求体。

## 构建与发现的失败

最终后端冻结源码全量458项，失败/错误/跳过0；前端最终冻结源码239项，失败/跳过0，类型检查与生产构建通过。
实际环回Triple STRICT及HTTP TCP验证冲突类型、无cause、409/400和不回显敏感输入；
领域为明确冲突夹具，不冒充数据库测试。公网注册另外验证真实MySQL/RPC/登录Cookie。

全量测试曾发现注册命令未显式白名单，在已有安全编解码测试初始化后的进程中被拒绝；
补精确契约后全量重跑，不用关闭STRICT解决。
新增准备前置读取后，原测试需等待确实进入凭据在途再修改版本；补独立准备期撤权用例，保留两个异步边界。

公网阶段保留实际失败：初版新成员加入后操作旧版本冲突；
修改麦位后过早申请凭据遇到旧版本/清退未就绪；最终下麦曾被读取/焦点/续约时序抢占。
分别补前置核验、连接读取保护、有界清退等待及独占准备窗口，随后重跑完整GUI流程通过。
并行认证测试曾触发既有限流429，未降低限流或计作成功；独立窗口后原生SDK测试通过。

## 仍需实际使用验证

- 手机/电脑使用不同账号，在同一房间保持前台，按[使用指南](VOICE_USER_GUIDE.md)复测权限、麦克风、媒体音量、蓝牙输出及播放恢复。
- 手机锁屏、后台持续通话目前不支持；失权后不自动开麦。房管修改权限时可能须按最新状态重新连接。
- 真实硬件、弱网、多人容量、告警闭环及异地灾备仍需专项验收。LiveKit懒加载产物仍有Vite大包警告。
