# 绑定释放人工恢复实施计划

承接只读运维，不缩减企业交付路线阶段 2～9；本计划未通过前不声明恢复闭环完成。
生产默认关闭，不自动选择负责人账号、赋权、安装规则或公开管理端口。

## 不变量

- 原 requestId 是已提交业务的绑定凭据，commandId 是人工受理幂等键，不能混用。
- 只受理无租约的 DEAD；每个原任务最多十次人工恢复，每代最多十次领取。
  原 attempts 累计永不清零；新增 generationAttempts 仅代表本代预算。
- 受理与追加审计同库事务；同命令重试返回原事实，同键改目标/账号/代次/原因拒绝。
  不发送同步 RPC，不将排队受理写成释放完成或资产删除。
- 独立 asset:binding:replay、独立确认表/编码动作域；密码限速使用已提交的每账号预算。
  确认绑定当前账号、会话、业务域、完整命令、授权/密码版本和数据库到期。
- 当前读权限用于查询原命令受理事实与审计；404 不证明在途提交已经终止。
  前端保留不确定原命令，不能重新生成 ID 后盲重试；切页、卸载、撤权及时清秘密。
- 旧租约成功/失败不得覆盖新代次；不释放无提交凭据的未知意图，不启动 READY 删除。

## 实施与验收

1. 新 V15（两域）和身份 V16、独立契约/权限/确认；旧迁移哈希不变。
2. 核心锁、幂等、同库排队/审计；worker 本代预算与累计次数；有界读审计。
3. Gateway 当前身份/会话摘要、HTTP 202/no-store、严格 Dubbo 白名单与固定域。
4. Web 二次确认、原命令恢复查询/重试、审计分页、加载/错误与身份隔离。
5. 全量单元/HTTP/真实编解码、格式与构建；真实 MySQL 迁移/并发/旧租约/审计回滚。
6. 独立完整网络与授权浏览器、备份恢复、发布审批/部署/公网验收与定向清理。

每步以证据更新结果，不用 mock 证明 SQL 或旧截图证明新 UI。完整网络/发布不足时继续保留门槛。
先停用两个域所有旧 worker，迁移并升级全部新 worker/read Provider，再批准开启。
旧 worker 按 attempts<10 领取，不支持新人工代次，禁止混合版本启用恢复。
