## 本轮功能与规范落实

Java chat-service 增加 Flyway V3 个人消息收藏表、Lombok 实体、MP Mapper/XML、事务服务和 OpenAPI/Knife4j 契约，字段和语义补中文注释。沿用 Nacos/Dubbo/Gateway/Sa-Token/MP，不新增 JVM、搜索引擎或 Go 服务。收藏只保存本人对真实消息的引用；读取和写入均锁定 ACTIVE 会话并检查当前成员、入群序号，与移除/解散串行化，不缓存历史授权、不复制正文、不改变他人收藏。

搜索区分大小写、字面包含，2～64 UTF-16 字符，拒绝 NUL；`%/_/=` 不作通配符。每批最多扫描 2000 个序号、返回 50 条，空窗口仍可能有下一批游标；不宣称全文相关度排序。收藏每人每会话最多 1000 个引用，重试/取消/清空幂等，清空包含重加入后不可读的旧引用。查询使用绑定参数和超时保护，不把内部实体直接暴露到 HTTP。

前端在真实会话中提供「搜索 / 消息收藏」、分页、收藏/取消/清空确认、加载/错误/成功反馈。工具面板不自动标记隐藏聊天尾部已读；保存已提交搜索词，切换/卸载取消旧请求，忽略迟到响应。复查发现分页读取与取消收藏可能交错，增加读取中禁止写入的保护。客户端取消等待不表示后端写事务撤销，不用假成功替代真实响应。

按用户提供的 enterprise-development 规范执行跨层不变量、权限、真实 SQL 并发验证和备份后增量发布；computer-use 用于尝试实际页面验收，但其超时限制单独保留，不冒充通过。
