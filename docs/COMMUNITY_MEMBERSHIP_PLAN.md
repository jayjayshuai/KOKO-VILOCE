# 社区成员闭环计划

本轮补公开社区加入、本人退出、我的已加入社区、成员游标分页与所有者移除成员；前后端同步，不新增 JVM。社区关系不是 Netty 群聊或 LiveKit 房间权限，不伪造频道、邀请或通知完成。

## 不变量

- 只允许加入 ACTIVE/PUBLIC 社区；已是成员的重试可返回原关系，不增加人数。私密社区不开放自行加入，不实现猜测 ID 入会。
- 与编辑/归档共用社区行锁，成员写入和人数/版本同事务。所有者不能退出或被移除。最多 1000 人，唯一主键防重复，受影响行数必须检查。
- 本人社区列表仅包含当前成员的 ACTIVE 社区；成员列表仅当前成员可看，不向外人公开私密名称、人数或成员信息。
- 只持久化入会时的公开用户名/显示名称快照，不保存邮箱；历史所有者无快照显示角色/ID，不假造名称。依赖身份目录失败不创建关系。
- 自行退出无关系时成功、无副作用；归档后不再修改成员。移除不是永久封禁，公开社区可重新加入，界面明确提示。
- 前端真实响应后再显示成功，切换/卸载取消旧读取，写入失败不修改成员或人数；雪花 ID 一律字符串；每页最多 50。
- Flyway 新增 V9，不改变旧迁移或擅自修复历史生产数据。测试仅命名隔离库与精确合成账号/社区，清理前定向备份。
