# 语音房主工作台阶段计划

这是既有语音房生命周期的前后端管理补全，不是P1麦位/成员实现。代码通过阶段检查后提交，
服务器不自动发布；P0/TLS/媒体授权、持久补偿和容量门槛保持。

## 不变量与实现

- 本人列表按可信网关用户ID查询，不能指定其他房主；ID降序独占游标，每页1～50，最多查询51条。
- 列表返回公开房间投影及状态，不序列化供应商房间名/密钥；新增owner_id/id索引，不修改V1。
- 非所有者关闭返回404且不访问LiveKit；已关闭的本人重试幂等，不重新删除媒体房间。
- LiveKit删除失败/数据库确认未知不展示成功；CAS失败须读到本人CLOSED事实才能确认幂等成功。
- 关闭确认只表示删除调用成功且数据库关闭事实可确认，不宣称旧JWT立即失效；
  LiveKit可能依据仍有效的旧JWT自动创建房间，后续P1必须补授权与撤销/补偿。
- 入会凭据的toString不包含JWT，HTTP序列化仍保留必要短期token且no-store。
- 独立登录工作台真实请求、空态/失败/分页、明确关闭确认；重复提交受控，切页/换账号取消旧读取，
  迟到写回复不污染新页面。取消HTTP请求不意味着供应商或SQL写入被撤销，未确认须重取/重试。

## 验证和提交门槛

实际生产XML与限权独立MySQL验证迁移/本人游标/索引、关闭幂等/竞争/SQL失败；身份/媒体为
明确夹具，不冒充RTC。真实环回Tomcat验证可信头、私有列表、响应投影和204，
Vue运行真实setup验证分页/错误/重复关闭/卸载与轮次。全量构建、格式及暂存/历史隐私检查后提交。
浏览器视觉/移动端、真实LiveKit故障与生产发布另记，缺证据不得宣布阶段上线。
