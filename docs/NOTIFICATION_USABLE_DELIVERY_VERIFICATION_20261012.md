# 通知中心可用闭环交付（2026-10-12）

## 已完成并增量发布

- 收件箱保留已确认列表；第二页失败重试第二页，不重置为第一页。错误、加载及空列表分开表达。
- 已读请求发送前锁定原通知ID。回应丢失、提交成功但读取失败、目标不在当前页、无效时间均不能解锁或自动重发；只有读取到有效的已读事实才解除。
- 接收偏好按类型保留未知结果，其他类型保存成功不会清除旧的核实入口。三种偏好GET全部校验后原子应用；偏好慢写不阻塞刷新收件箱或标为已读。
- 换账号及同账号新登录重建私有页面；卸载中止请求并忽略迟到回包。业务401不继续展示旧身份通知。
- 提供“全部已加载”和“只看已加载未读”筛选，数量只来自已加载集合，不冒充全量未读数。已有通知和已读历史不因关闭偏好清空。
- 通知及偏好GET使用no-store。校验正Long字符串ID、通知类型、摘要和日期，异常响应保留旧列表；摘要以文本展示，不执行HTML。
- 服务端LocalDateTime按Asia/Shanghai解释并展示，不受浏览器所在地时区影响。非法日期拒绝，纳秒仅在显示转换时截取，原始readAt不改写。

只发布冻结的前端，未重启Java服务、Nacos或媒体服务，未执行数据库迁移或直接SQL写入。实际业务API在隔离测试账号下创建测试数据；不能将“未直接写SQL”理解为没有业务数据库写入。

## 使用与后续边界

侧栏进入“通知中心”，可逐条标为已读、加载更多、筛选已加载未读，并按类型切换接收偏好。未知提交先选择重新读取，不反复点击写入；关闭类型只影响后续事件，不删除旧通知。

全量未读统计、批量已读、稳定游标、通知资源跳转、外部推送、多节点容量、持续磁盘告警和失败事件处置仍未完成；本轮真实业务触发验证覆盖COMMENT，不将FOLLOW或LIVE_STARTED显示开关等同于二者实际事件完整验收。IP证书续期、物理手机后台策略、直播及Discord仍按各自阶段验收。

GET核实偏好是服务端时点事实，不是原PUT的幂等收据；跨窗口并发或服务端迟到写入仍需要后端版本/幂等契约，不能保证后续状态不变。未知已读状态目前只在该页面生命周期内保留，不宣称刷新页面后的持久请求恢复。

公开仓库可重复运行`npm --prefix web test`、`npm --prefix web run build`、`npm run test:format`及`npm run check:secrets`。实际部署及生产联调需要自己的私有凭据、受信证书和隔离测试账号，不以夹具PASS代替真实投递证据。
