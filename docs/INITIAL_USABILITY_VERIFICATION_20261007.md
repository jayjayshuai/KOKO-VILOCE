## 实现

- 五个发现分区独立读取、取消、结果、错误和重试；语音500不会隐藏正常内容，
  慢服务不阻塞正常文章分页，旧请求不能覆盖新的成功快照，未知计数显示破折号。
- Gateway 包装自动配置的 WebSocketService，保留原 RequestUpgradeStrategy 和生命周期。
  首次完整启动发现重复同名Bean，修复后真实八Boot启动通过，未打开Bean覆盖配置。
- 媒体信令已有连接在独立有界池持续检查网站会话、身份目录、房间/成员租约和绑定轮次。
  资源满关闭1013，核验拒绝或故障关闭1008，连接结束归还槽位；修正关闭帧取消竞态和重复延迟。
- 签名UUID仅是媒体绑定投影，SQL负责核对当前用户/成员session/身份/席位与publish声明；
  新入会等待未退场或DEAD任务，已有未变化绑定不受其他用户任务影响。开关仍默认false。
- 增加 `npm run check:environment -- --api-base <地址>`，无凭据GET检查、禁止自动重定向、
  校验JSON外形、限制响应大小与等待；报告仅含状态，不输出用户记录或原始依赖错误。
- 私有本地启动器保留远程现有数据库只读调试，新增本机45173→服务器80的SSH转发访问已部署版本。
  启动器、凭据、IDE附加配置和证据不提交。
